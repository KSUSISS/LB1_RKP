## Цель работы
Изучить основы создания веб-приложений на базе Spring Boot и шаблонизатора Thymeleaf, реализовав приложение для получения, обработки (генерация названия группы и логина) и вывода данных студента через HTML-формы.

## Архитектура проекта
- **Стек:** Spring Boot 4.1.1, Maven, Java 21, Thymeleaf, HTML/CSS.
- **Основные слои:** 
  - **Controller (`MainController`):** Принимает HTTP-запросы (GET и POST), управляет переходами между страницами и передает данные в модель.
  - **Model (`Student`):** POJO-класс для сбора данных с формы, который также содержит бизнес-логику для вычисления названия группы и логина.
  - **View (Представление):** HTML-страницы (`main-form.html`, `result.html`) с использованием тегов Thymeleaf для рендеринга данных на стороне сервера.
- **Ключевые аннотации:** 
  - `@Controller` — указывает, что класс является веб-контроллером Spring MVC.
  - `@GetMapping` — обрабатывает GET-запросы (например, открытие пустой формы).
  - `@PostMapping` — обрабатывает POST-запросы (отправка заполненной формы).
  - `@ModelAttribute` — связывает данные, пришедшие из HTTP-запроса, с объектом Java.

## Алгоритм работы
1. Пользователь обращается по адресу `/form` (GET-запрос).
2. Метод `mainForm` в контроллере создает пустой объект `Student`, передает его в модель и возвращает шаблон `main-form.html`.
3. Пользователь видит HTML-форму, заполняет поля (ID, ФИО, email, год поступления) и нажимает «Отправить».
4. Данные уходят на сервер POST-запросом на адрес `/form`.
5. Метод `mainFormSubmit` перехватывает запрос. Spring автоматически собирает данные формы в объект `Student` благодаря аннотации `@ModelAttribute`.
6. Вызывается внутренний метод `generateStudentInfo()` у объекта `Student`, который на основе года поступления вычисляет и заполняет поля `groupName` (например, ПИН3-120) и `login`.
7. Заполненный объект `Student` со всеми сгенерированными полями добавляется в объект `Model`.
8. Контроллер возвращает шаблон `result.html`, где с помощью Thymeleaf отображаются все полученные и сгенерированные данные.
